# Bedtime

1. Read the canonical [delivery policy](../../../AGENTS.md#delivery-policy) before
   starting. Apply its repository overrides throughout the run, including when
   following Poteto/pstack playbooks.
2. Record the requested outcome, existing merge/deployment authority and next
   landable unit. Execute the queue under that policy; keep the record current
   when a unit lands or a dependency blocks progress.
3. Finish with the changed files, verification evidence, PR/merge status and any
   exact outstanding dependencies. Use the policy's completion states.
